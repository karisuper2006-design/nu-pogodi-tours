### 2. `bot.py:473-488` — поддержка принудительного polling-режима

Render автоматически ставит переменную `RENDER_EXTERNAL_URL`, из-за чего бот всегда пытается работать в webhook-режиме. На бесплатном тире Render засыпает через 15 мин — webhook ломается. Polling надёжнее.

Добавить поддержку переменной `USE_POLLING`:

```python
# Было (bot.py:473-488):
    # Cloud (Render) → webhook mode; Local → polling mode
    webhook_url = os.environ.get("RENDER_EXTERNAL_URL", "")
    port = int(os.environ.get("PORT", "10000"))

    if webhook_url:
        logger.info(f"🌐 Webhook mode: {webhook_url}")
        app.run_webhook(
            listen="0.0.0.0",
            port=port,
            webhook_url=f"{webhook_url}/webhook",
            url_path="webhook",
            allowed_updates=Update.ALL_TYPES,
        )
    else:
        logger.info("🤖 Polling mode (local)")
        app.run_polling(allowed_updates=Update.ALL_TYPES)

# Стало:
    # Cloud (Render) → webhook mode; Local → polling mode
    # Use USE_POLLING=true to force polling (recommended for free tier)
    use_polling = os.environ.get("USE_POLLING", "").lower() in ("true", "1", "yes")
    webhook_url = os.environ.get("RENDER_EXTERNAL_URL", "")
    port = int(os.environ.get("PORT", "10000"))

    if webhook_url and not use_polling:
        logger.info(f"🌐 Webhook mode: {webhook_url}")
        app.run_webhook(
            listen="0.0.0.0",
            port=port,
            webhook_url=f"{webhook_url}/webhook",
            url_path="webhook",
            allowed_updates=Update.ALL_TYPES,
        )
    else:
        logger.info("🤖 Polling mode")
        app.run_polling(allowed_updates=Update.ALL_TYPES)
```


### 3.4 Задеплоить бота на Render
1. Зарегистрироваться на https://render.com (через GitHub)
2. Новый → **Background Worker** (не Web Service!)
3. Подключить репозиторий `karisuper2006-design/nu-pogodi-tours`
4. Настройки сервиса:
   - **Name**: `nu-pogodi-bot`
   - **Runtime**: Python 3
   - **Build Command**: `pip install -r requirements.txt`
   - **Start Command**: `python bot.py`
5. В секции **Environment Variables** добавить:
   | Key | Value |
   |-----|-------|
   | `BOT_TOKEN` | токен Telegram бота |
   | `ADMIN_USER_ID` | `784414110, 1930334798` |
   | `GITHUB_TOKEN` | новый токен GitHub |
   | `USE_POLLING` | `true` |
6. **Create Background Worker**
7. Дождаться деплоя (статус "Live")

> **Почему Background Worker, а не Web Service?**
> Background Worker не требует HTTP-порта, идеально подходит для polling-режима бота. Не засыпает и не требует `PORT`/`RENDER_EXTERNAL_URL`.

### 3.5 Настроить GitHub Pages
- Settings → Pages → Source: Deploy from a branch → `master` / root

### 3.6 Настроить DNS (если домен привязан к старому аккаунту)
