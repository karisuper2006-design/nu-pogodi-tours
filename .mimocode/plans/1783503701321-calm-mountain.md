# Диагностика 404 ошибки сайта nupogodi-tours.ru

## Контекст
- Статический HTML-сайт (туры по Бурятии/Сахалину)
- Хостинг: GitHub Pages + кастомный домен `nupogodi-tours.ru`
- Репозиторий: `Trackunsocket/nu-pogodi-tours`, ветка `master`
- Деплой: GitHub Actions (`.github/workflows/deploy.yml`)
- CNAME файл присутствует в корне

## Вероятные причины 404 (от наиболее к менее вероятной)

### 1. DNS домена не настроен или упал
**Самая частая причина 404 на кастомном домене.**
- Домен `nupogodi-tours.ru` должен иметь A-записи на IP GitHub Pages:
  ```
  185.199.108.153
  185.199.109.153
  185.199.110.153
  185.199.111.153
  ```
- Либо CNAME-запись `@` → `Trackunsocket.github.io`
- Проверка: `dig nupogodi-tours.ru A` или `nslookup nupogodi-tours.ru`

### 2. GitHub Pages не включён в настройках репозитория
- Настройки → Pages → Source должен быть "GitHub Actions"
- Если source выставлен на другую ветку (например `main`), деплой не сработает

### 3. Последний деплой workflow упал
- Нужно проверить вкладку Actions в репозитории — были ли ошибки
- Workflow триггерится на push в `master`, если были ошибки в Actions, сайт не обновился

### 4. Кастомный домен сброшен в настройках GitHub
- Если домен был удалён из настроек Pages, CNAME файл не поможет — GitHub его игнорирует без соответствующей настройки
- Нужно проверить: Settings → Pages → Custom domain — указан ли `nupogodi-tours.ru`

### 5. SSL-сертификат не выпущен
- GitHub Pages автоматически выпускает SSL для кастомных доменов
- Если DNS только что настроен, сертификат может ещё не выпуститься (до 24ч)
- Проверка: Settings → Pages → должен быть зелёный замок

## План действий

### Шаг 1: Проверить DNS (выполнить в терминале)
```bash
dig nupogodi-tours.ru A
nslookup nupogodi-tours.ru
```
Убедиться, что IP-адреса совпадают с GitHub Pages (185.199.108-111.153).

### Шаг 2: Проверить GitHub Actions
- Открыть https://github.com/Trackunsocket/nu-pogodi-tours/actions
- Посмотреть статус последних деплоев — были ли ошибки

### Шаг 3: Проверить настройки GitHub Pages
- Settings → Pages → Source: должен быть "GitHub Actions"
- Custom domain: должен быть `nupogodi-tours.ru`

### Шаг 4: Если DNS в порядке, но 404 сохраняется
- Пересоздать CNAME: удалить из настроек Pages, подождать 5 мин, добавить заново
- Это перезапустит выпуск SSL-сертификата

## Файлы для проверки/модификации
- `CNAME` — содержит домен `nupogodi-tours.ru` (не менять, если DNS корректен)
- `.github/workflows/deploy.yml` — workflow деплоя (конфигурация корректна)
- DNS-записи у регистратора домена (вне репозитория)

## Верификация
1. После исправления DNS: `dig nupogodi-tours.ru` → IP GitHub Pages
2. Открыть https://nupogodi-tours.ru — сайт должен загрузиться
3. Также проверить https://trackunsocket.github.io/nu-pogodi-tours/ — должен работать через GitHub Pages URL
