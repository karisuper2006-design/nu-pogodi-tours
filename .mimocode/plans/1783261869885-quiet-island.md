# Исправление обновления дат на сайте

## Проблема

Бот (`bot.py`) меняет даты в `tours_data.json`/`tours_data.js` локально, но не пушит изменения на GitHub → сайт не обновляется.

**Причины:**
1. `GITHUB_REPO` в `bot.py:48` указывает на старый аккаунт `karisuper2006-design/nu-pogodi-tours`
2. `GITHUB_TOKEN` не задан в переменных окружения → `git_push()` молча пропускает push

## Исправления

### 1. Обновить `GITHUB_REPO` в `bot.py`

**Файл:** `bot.py:48`

```python
# Было:
GITHUB_REPO = "karisuper2006-design/nu-pogodi-tours"

# Стало:
GITHUB_REPO = "Trackunsocket/nu-pogodi-tours"
```

### 2. Добавить `GITHUB_TOKEN` в `.env`

**Файл:** `.env`

Добавить строку:
```
GITHUB_TOKEN=<токен>
```

> Токен нужно создать вручную:
> 1. Перейти на https://github.com/settings/tokens
> 2. "Generate new token (classic)"
> 3. Выставить expiration (рекомендую 90 дней или "No expiration")
> 4. Отметить scope: **repo** (полный доступ к приватным репозиториям) или **public_repo** (если репозиторий публичный)
> 5. Скопировать токен и вставить в `.env`

### 3. (Опционально) Обновить git remote

Текущий remote всё ещё на старый аккаунт. Если нужно — обновить:
```bash
git remote set-url origin https://github.com/Trackunsocket/nu-pogodi-tours.git
```

## Верификация

1. После правок запустить бота локально и через Telegram-интерфейс изменить дату тура
2. Проверить, что в логах нет `"GITHUB_TOKEN не задан, пропускаем push"`
3. Проверить коммит на GitHub: https://github.com/Trackunsocket/nu-pogodi-tours/commits/main
4. Открыть сайт и убедиться, что дата обновилась (cache-buster `?t=timestamp` подхватит новый файл)
